/*Sistema de Gestão Plalum*/
Este repositório contém o software de exemplo desenvolvido para a UC de Análise de Sistemas. O projeto visa a modernização do sistema de gestão de uma fábrica de Placas metálicas, substituindo o modelo manual atual.

A aplicação foi rigorosamente estruturada utilizando o padrão arquitetural Boundary-Control-Entity (BCE), com foco na alta coesão e no baixo acoplamento. Todo o código-fonte funciona como uma excelente base de estudo e evolução prática para programadores, unindo os fundamentos teóricos da engenharia de software com a aplicação de regras de negócio em cenários reais da associação.

Pré-requisitos
Para preparar o ambiente de desenvolvimento, é indispensável a instalação de quatro ferramentas para o seu ambiente de desenvolvimento:

/*PHP:*/ Transfira os binários diretamente do site oficial e garanta que o caminho do executável está adicionado às variáveis de ambiente da sua máquina.
/*Composer:*/ Após instalar o PHP, instale o gestor de dependências para lidar com o autocarregamento das classes do projeto.
/*MySQL:*/ Configure o SGBD de forma independente. O serviço deve estar obrigatoriamente em execução antes de testar a aplicação.
/*Cliente MYSQL:*/ Use qualquer um de sua preferência. Ex: MySQL Workbench, DBeaver, Beekeeper Studio, etc.
